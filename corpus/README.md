# Corpus

Pages that exercise the HTML and CSS a surface is expected to handle. Each page
states at the top what it tests, and reads at 80×24 cells. A host's
fidelity is judged by rendering these pages next to a browser's rendering of
them (hotty-blitz does this with Chromium as the reference).

The pages use the host stylesheet's custom properties (`--hotty-fg`,
`--hotty-ansi-*`, `--hotty-font`; SPEC §8), so they follow the terminal's
theme.

may come before it is.

## Accepted

- [ ] **V4-01** Key names are myelin's
      status: accepted (the maintainer, 2026-10-17), building on `hotty-0.4` | added: 2026-10-17
      problem: §10.4 named keys by the W3C's key values (`Control+a`,
      `ArrowLeft`), while the keymaps programs share, and Ghostty, spell
      them another way: one keymap needed two spellings.
      proposal: §10.4 cites *myelin key names* 0.1 at the tag
      `myelinkey/v0.1.0` for the names, matching and reading, `mod`
      included (its §4.4), and keeps only how a host names a press. A press
      seen as pressed has a physical name and a character's, looked up
      physical first. The capabilities' `mod` is `ctrl` or `super`.
      cost: every key name on the wire, in documents and in vectors
      changes. A 0.4 host and a 0.3 program meet at the version check
      (`EVERSION`), not at a binding that silently does nothing.
      settled while building: a command's key is the one name its bytes
      have (§10.6); a press given to the program as pressed, by its
      physical name, stays the program's when it comes again as bytes
      (§10.4), which the headless run in hottyterm found broken.

## Proposed

Open points that a version could settle, none weighed yet:

- **`reveal` and `view` at their edges** (§9.5): a zero-area element, the
  last element that asks going away, an element in the window but clipped
  by a box, a placement scrolled off the terminal. The two hosts differ on
  some, and no vector covers them.
- **Scrolling keys in a one-line field:** a host scrolls the surface on
  `page_down` or `arrow_up` in an `input`, where §10.2 gives a key the
  field lacks an action for to the program.
- **A modifier tapped alone** (§10.4) is offered on its release, sided
  and as a modifier key. Settled on the branch: it
  reaches the program only as bytes, which name no modifier key, so a tap
  bound to `program` or `prefix` does nothing. Open: whether a program
  that asked the kitty protocol for every key should get it, which would
  make a tap a leader. hotty-blitz offers a tap to a field's keymap;
  xterm-addon-hotty does not offer it yet.
